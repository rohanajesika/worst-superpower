A program that writes one line inventing the most useless superpower — summoning rain, but only indoors, right above its owner's head, one drop at a time — to `/output/entry.txt`. One sentence, 81 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "Worst Superpower" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
